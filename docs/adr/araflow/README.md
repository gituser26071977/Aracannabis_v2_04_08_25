# Architecture Decision Records — AraFlow

> **Status:** Repositório de ADRs da Constituição Técnica.

ADRs são imutáveis uma vez publicados. Decisões subsequentes que
invalidam um ADR devem:

1. Criar novo ADR referenciando o anterior.
2. Marcar o ADR anterior como `Superseded by ADR-NNN`.
3. Atualizar a Constituição Técnica (se aplicável).

## Convenção de nomenclatura

`NNNN-titulo-em-kebab-case.md`

Exemplo: `001-clean-architecture.md`

Ver `docs/adr/araflow/template.md`.
