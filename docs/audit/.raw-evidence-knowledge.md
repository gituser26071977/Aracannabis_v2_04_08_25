- KnowledgeGraph: graph_id obrigatório, IDs únicos, edges source/target ∈ nodes, weight ∈ [0,1], state_hash
- ResearchSession: session_id/result_json/state_hash obrigatórios, ordem timestamps, reprodutibilidade

## Discrepância hypothesis_id (CONFIRMADA)
- Manifest (PUBLIC_API_MANIFEST.md:335): `tenant_id|rule_name|gene_ids_sorted|correlation_id`
- Código (hypothesis.py:68-75): `rule_id|sorted(gene_ids)|sorted(correlation_ids)|claim`
- SEM tenant_id na composição → cross-tenant leak real
- Task #197 pendente

## Cross-tenant boundary
- ClinicalGene, ClinicalGenome, Cohort, KnowledgeGraph: têm tenant_id; _assert_same_tenant protege
- CorrelationResult, ClinicalHypothesis, ResearchSession: NÃO têm tenant_id; dependem de context repository + IDs content-derived (parcial)
