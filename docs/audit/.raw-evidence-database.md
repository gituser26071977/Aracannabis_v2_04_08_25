## Risks identificados
- Multi-tenancy inconsistente (3 estratégias)
- Models órfãos (migrations criam sem model SQLAlchemy) — possível inconsistência runtime
- FKs sem ondelete explícito (default NO ACTION silencioso)
- CheckConstraint só no model (não na migration) — depende de db.create_all()
- araos_clinical_diagnoses/etc SEM deleted_at
- AuditFieldsMixin só em modelos SQLAlchemy 2.0 declarativos
