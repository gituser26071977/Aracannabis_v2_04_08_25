## 1. Princípios éticos de IA

1. **A IA sugere; o humano decide.** Nunca prescreve; nunca substitui o profissional.
2. **Transparência.** Toda recomendação tem explicação simples ("porque você…").
3. **Consentimento explícito** para uso de IA personalização profunda.
4. **Auditoria contínua** dos modelos.
5. **Não usar dados sensíveis** (raça, religião, orientação sexual) como features.
6. **Sem dark patterns.** IA não manipula para gerar engajamento.
7. **Comitê clínico** revisa periodicamente os outputs.
8. **Direito a não usar IA.** Usuário pode usar AraFlow "sem IA".

---

## 2. Limites do que a IA pode e não pode fazer

| Pode | Não pode |
|------|----------|
| Recomendar protocolos com base em histórico | Diagnosticar condições |
| Identificar padrões de uso | Substituir avaliação clínica |
| Alertar o profissional sobre sinais | Prescrever doses medicamentosas |
| Personalizar horários de sessão | Tomar decisões terapêuticas autônomas |
| Sugerir ajustes de protocolo | Comentar sobre outros tratamentos |
| Explicar ciência ao paciente | Garantir desfechos clínicos |
| Detectar baixa adesão | Forçar engajamento |

> ⚠ **Regra de ouro:** se a saída da IA puder ser lida como "diagnóstico" ou "conduta clínica autônoma", ela deve ser refreada e o profissional consultado.

## 4. Personalização de protocolos

### 4.1 MVP (sem ML)

Recomendação por **regras baseadas em objetivo** declarado:

```ts
if (objetivo === "ansiedade" && hora === "manhã")
  → recomendar "Coerência 5.5" 5min

if (objetivo === "sono" && hora === "noite")
  → recomendar "4-7-8" 5min

if (objetivo === "foco" && hora === "trabalho")
  → recomendar "Box breathing" 5min
```

### 4.2 Fase 2 (ML supervisionado leve)

Modelo aprende:

- Que objetivo é mais usado pelo paciente.
- Que horário tem maior adesão.
- Que duração é mais bem tolerada.
- Que estilo de visual preferido.

**Variáveis:**

- Dia da semana.
- Hora.
- Estado autorrelatado (escala 1-5 antes/depois).
- Histórico de sessões concluídas.
- (opt-in) dados clínicos básicos.

**Modelo:** regressão logística / árvore de decisão / modelo linear regularizado. Explicável por natureza.

**Output:** ranking de protocolos candidatos + explicação.

### 4.3 Fase 3 (modelos mais ricos)

- Modelos de sequência (LSTM/Transformer leve) para prever próxima melhor sessão.
- Aprendizado por reforço com limites (bandits contextuais).
- Personalização por objetivo clínico cruzado (ex: paciente com ansiedade + TDAH).

## 5. Identificação de padrões

### 5.1 Padrões de uso

- **Horários mais comuns.**
- **Categorias preferidas.**
- **Duração média tolerada.**
- **Frequência semanal real.**
- **Padrão de fim de semana** vs semana.
- **Sazonalidade.**

### 5.2 Padrões clínicos (Fase 2)

- Correlação entre sessões e **escala subjetiva** (antes vs depois).
- Correlação entre uso e **GAD-7/ISI ao longo do tempo**.
- **Variabilidade da adesão** como marcador prognóstico.
- Identificação de **gatilhos** (ex: queda de adesão antes de crises).

### 5.3 Padrões populacionais (Fase 3)

- Comparação anonimizada com coortes semelhantes.
- Benchmarking ("pacientes com perfil similar tiveram melhora média de X").

## 6. Recomendações

### 6.1 Tipos de recomendação

| Tipo | Origem |
|------|--------|
| **Próxima sessão** | Modelo preditivo + horário |
| **Ajustar dose** | Adesão + escores |
| **Tentar novo protocolo** | Diversidade + aceitação |
| **Modo sono** | Horário + escala subjetiva |
| **Modo SOS** | Sinais de pico (escala pré-sessão alta) |

### 6.2 Formato da recomendação

- Curta: 1 frase.
- Explicada: 1 bullet.
- Acionável: botão direto.

> Exemplo:
> *"Parece que manhãs funcionam melhor para você. Que tal coerência 5.5 agora?"*
> [Começar agora] [Depois]

### 6.3 Tom

- Sugestivo, nunca impositivo.
- "Que tal" > "Você deveria".
- Sempre oferecer alternativa.

## 7. Acompanhamento de adesão

### 7.1 Sinais de alerta (regras MVP)

| Sinal | Regra |
|-------|-------|
| Queda brusca | Adesão cai > 50% em 7 dias |
| Inatividade | 7+ dias sem sessão |
| Efeito adverso | Reportado |
| Escala crítica | GAD-7 ≥ 15, PHQ-9 ≥ 20 |

### 7.2 Modelo preditivo (Fase 2)

- Predição de **abandono** em 14 dias.
- Predição de **resposta clínica** em 8 semanas.
- Predição de **necessidade de ajuste** de protocolo.

### 7.3 Ação

- **Ao paciente:** mensagem calorosa sem julgamento.
- **Ao profissional:** alerta no dashboard.
- **Nunca:** punição, perda de streak forçada.

## 8. Insights clínicos

### 8.1 Para o paciente

| Insight | Exemplo |
|---------|---------|
| Correlação sono/ansiedade | "Nos dias que você respira de manhã, sua ansiedade pré-sessão é 1 ponto menor." |
| Padrão de eficácia | "Coerência 5.5 reduz sua ansiedade em média 30%." |
| Horário ideal | "Sessões noturnas parecem funcionar melhor para você." |

### 8.2 Para o profissional

| Insight | Exemplo |
|---------|---------|
| Não-aderência | "Carlos reduziu adesão em 40% nas últimas 2 semanas." |
| Piora clínica | "GAD-7 subiu de 11 para 14; padrão coincide com queda de uso." |
| Resposta | "Helena responde melhor a sessões matinais + 4-7-8." |
| Risco | "Antônio tem baixa adesão + relatado evento adverso." |

### 8.3 Visual

- Cards explicativos com pequena frase + gráfico.
- Linguagem acessível (sem jargão).
- **Sempre** com link para ação ("ver detalhes", "falar com profissional").

## 9. Geração de conteúdo (Fase 3)

### 9.1 Tipos

| Tipo | Uso |
|------|-----|
| **Narração personalizada** | Body scan com nome do paciente |
| **Texto de acolhimento** | Mensagens dinâmicas por contexto |
| **Sugestões escritas** | "Que tal X hoje?" em tom humano |
| **Explicações clínicas** | Resumo acessível de evidência |
| **Conteúdo educativo** | Artigos curtos personalizados |

### 9.2 Guardrails obrigatórios

- Toda saída gerada passa por **camada de validação clínica**.
- Lista de termos banidos (não pode citar remédio, dose, marca).
- Revisão por amostragem semanal.
- Logs auditáveis.

### 9.3 Modelo

- LLM interno fine-tunado em conteúdo AraOS.
- Ou LLM de mercado com **RAG sobre base AraFlow**.
- Sempre com **filtro clínico** antes de chegar ao usuário.

## 10. Biofeedback inteligente (Fase 3)

### 10.1 Entrada

- HRV (PPG/ECG) em tempo real.
- Pulso.
- (futuro) GSR, temperatura.

### 10.2 Processamento

- Janela de 30–60s.
- Cálculo de RMSSD, coerência, tendência.
- Em tempo real no cliente.

### 10.3 Saída

- Visual respiratório **se adapta** ao HRV.
- Áudio modula timbres.
- Tom do metrônomo ajusta.
- Mensagem breve: "Sua coerência está subindo. Continue."

### 10.4 Modelos

- Regressão para coerência instantânea.
- Modelo de fase respiratória ótimo baseado em HRV.
- Análise de tendência para antecipar fadiga autonômica.

## 11. Modelo de dados para IA

### 11.1 Features (todas opt-in)

- Idade, sexo biológico, objetivo principal.
- Histórico de sessões (datas, durações, conclusão, escore subjetivo).
- Horários típicos.
- Adesão histórica.
- Escalas clínicas (GAD-7, ISI, PSS-10).
- (Fase 3) HRV, sono autorrelatado.

### 11.2 Variáveis **proibidas**

- Raça, etnia.
- Religião.
- Orientação sexual.
- Opinião política.
- Diagnóstico completo (apenas categorias amplas, opt-in).

### 11.3 Label

- Resposta clínica (escala contínua).
- Engajamento futuro (adesão 14d).
- Satisfação (escala 1-5).
- Evento adverso (binário).

## 12. Treinamento e avaliação

### 12.1 Pipeline

```
Coleta (consentida) → Limpeza → Feature engineering → Treino → Avaliação → Deploy → Monitoramento
```

### 12.2 Métricas

| Tipo | Métrica |
|------|---------|
| Classificação | AUC, F1, calibração |
| Ranking | NDCG, MAP |
| Regressão | MAE, RMSE |
| Texto (Fase 3) | BLEU, ROUGE + revisão humana |

### 12.3 Avaliação clínica

- Co-revisão com profissional sênior.
- Aprovação por amostragem.
- Comparação com desfechos clínicos reais.

### 12.4 Testes adversariais

- Verificar respostas a entradas hostis.
- Verificar ausência de viés.
- Verificar robustez a dados faltantes.

## 13. Guardrails clínicos

### 13.1 Lista de outputs proibidos

- Diagnóstico explícito ("você tem X").
- Recomendação medicamentosa.
- Comentário sobre outro profissional.
- Avaliação de gravidade clínica.
- Sugestão de internação.
- Conteúdos que violem LGPD.

### 13.2 Implementação

- **Lista negra** de frases (regex).
- **Classificador** treinado para detectar violação.
- **Revisão humana** antes de ativar feature sensível.
- **Modo degradado** se classificador falhar.

### 13.3 Escalation

- Toda recomendação sensível gera **alerta para o profissional** (se houver consentimento).

---

## 14. Auditoria e explicabilidade

### 14.1 Explicabilidade

- Toda recomendação tem **rastro explicável**.
- SHAP values para modelos supervisionados (Fase 2).
- Texto natural para usuário final.

### 14.2 Logs

- Toda recomendação é logada com versão do modelo.
- Permite reprocessamento se modelo mudar.
- Mantém histórico de saídas.

### 14.3 Auditoria

- Trimestral: revisão de amostras.
- Anual: auditoria externa.
- Por evento adverso: revisão imediata.

---

## 15. Privacidade

### 15.1 Treinamento

- Modelos treinados com dados **anonimizados**.
- Sem identificação pessoal em datasets.
- Sem uso de dados de pesquisa sem consentimento específico.

### 15.2 Inferência

- Inferência roda no servidor (modelos grandes) ou cliente (modelos leves).
- **Sem enviar dados sensíveis** para modelos de mercado.
- Quando inevitável, **contratos enterprise + criptografia**.

### 15.3 Edge AI

- Fase 3: modelos leves rodam no dispositivo.
- Privacidade máxima; latência mínima.

## 16. Roadmap

| Fase | Capacidade de IA |
|------|------------------|
| **MVP** | Regras if-then + ranking simples |
| **Fase 2** | Modelos supervisionados + personalização + insights básicos |
| **Fase 3** | Biofeedback + LLM com guardrails + edge AI |

---

## 17. Riscos e mitigações

| Risco | Mitigação |
|-------|-----------|
| Viés em dados | Auditoria regular; datasets diversos. |
| Dependência emocional | Limites de mensagens; tom humano; profissional visível. |
| Alucinação (Fase 3) | Guardrails + revisão humana. |
| Privacidade | Edge AI + anonimização + opt-in. |
| Over-engagement | Limites de notificações; horários de silêncio. |
| Substituição de profissional | Limites explícitos; profissional sempre visível. |
